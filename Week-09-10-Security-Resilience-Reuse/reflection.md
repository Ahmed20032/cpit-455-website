# Week 09-10 Reflection

- This week made me notice that reuse is not only for code libraries; it also matters in documentation structure.
- Reusing the same weekly pattern saves time and reduces mistakes.
- Security was also easier to apply after I separated what must be shown from what does not need to be public.
- Resilience became practical for me when I saw that one update should not damage previous weeks.
- I now see clean repetition as a strength, not a lack of creativity.
