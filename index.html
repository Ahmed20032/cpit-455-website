Group Project

Real project summary based on our software engineering submission

Domain

Usaruna Platform
An e-commerce marketplace for empowering family businesses in Saudi Arabia by connecting productive families with customers through a secure, organized, and logistically integrated web platform.

Quality Attributes
  • AAvailability: designed for high uptime during peak ordering periods
  • RReliability: orders, payments, and product data should be processed correctly every time
  • SSecurity: secure authentication, encrypted data handling, and protected payments
Engineering Evidence
  • 🏗Architecture: React + Vite frontend, Node + Express backend, and Supabase as the database/auth layer
  • ♻Reused Components: Tailwind CSS, Supabase Auth, Supabase Storage, Moyasar API, and Google Maps API
  • ⚠Risk Thinking: ALARP and fault-tree analysis used to improve trust, delivery, and failure handling
Architecture & Project Notes
System Overview
Usaruna addresses weak buyer trust, poor order management, low product visibility, and insecure payment handling for family businesses.
