# Week 05-06 Evidence V2

## Topic
Reliability engineering, fault-error-failure flow, and practical metrics.

## Final V2 Submission
- I mapped the reliability chain to the portfolio workflow:
  - Fault: a wrong folder name or missing file
  - Error: the page points to an invalid path
  - Failure: the instructor cannot open the required evidence
- I used this chain to improve the structure before final submission.
- I identified availability and reviewer access as the most meaningful reliability outcomes for this portfolio.

## Reliability Metrics Applied
- File accessibility: every week should open from the main page
- Naming consistency: each week follows the same file pattern
- Review success rate: the reviewer should reach the evidence in one or two clicks

## Practical Reliability Rules
- Use stable names across all weeks
- Do not mix evidence and reflection in one file
- Check links after every content update
- Keep the same layout and folder pattern from week to week
