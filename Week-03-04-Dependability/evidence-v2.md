# Week 03-04 Evidence V2

## Topic
Dependability: availability, reliability, safety, security, resilience, and sources of failure.

## Final V2 Submission
- I treated the portfolio itself as a small system that should be dependable for the reviewer.
- Availability means the files open when needed and the weekly folders are reachable.
- Reliability means the same structure works every week without broken paths or random naming.
- Safety means avoiding submission mistakes that could cause loss of marks or confusion.
- Security means avoiding unnecessary private data and keeping only safe student information in the public view.
- Resilience means the portfolio can be updated week by week without destroying the rest of the structure.

## Sources of Failure Identified
- Wrong folder names
- Broken file links
- Missing reflection files
- Evidence hidden inside one long page with no clear structure
- Unclear file names such as generic assignment labels

## Applied Improvement
- I replaced vague navigation with direct links to each week's evidence and reflection files.
- I kept repeated naming conventions so the structure can survive future edits.
